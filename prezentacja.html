Obliczanie kąta — calculate_true_angle()

def calculate_true_angle(a, b, c, w, h):
  # Denormalizacja punktów (0-1 → px)
  A = [a.x*w, a.y*h]
  B = [b.x*w, b.y*h]
  C = [c.x*w, c.y*h]

  # arctan2 na dwóch wektorach wychodzących z B
  rad = arctan2(C[1]-B[1], C[0]-B[0]) \
      - arctan2(A[1]-B[1], A[0]-B[0])

  angle = abs(rad * 180/π)
  return 360-angle if angle > 180 else angle

Bark (a) → Łokieć (b) → Nadgarstek (c).
Denormalizacja do pikseli zapewnia poprawne kąty niezależnie od proporcji kadru.

Widoczność ręki musi być > 0.40 (średnia z 3 punktów) — inaczej reset stanu i event TRACKING_LOST

TTS — kolejka z priorytetem

class VoiceManager:
  def __init__(self):
    self.q = queue.Queue()
    Thread(target=self._tts_worker).start()

  def speak(self, text, interrupt=False):
    if interrupt:
      # Atomowe czyszczenie kolejki
      with self.q.mutex:
        self.q.queue.clear()
    self.q.put(text)

  • Temporate=175 słów/min — szybkie ale zrozumiałe

Ekran TFT — Rendering Bez Mrugania

Kluczowy problem: fillScreen(BLACK) co klatkę powoduje migotanie. Rozwiązanie: oddzielenie zmiany widoku od aktualizacji danych

Technika: zmienna stanu ekranu

int aktualnyStanEkranu = -1;

void odswiezEkran() {
  int nowyStan = wTreningu ? 1
    : deviceConnected ? 0 : 2;

  // fillScreen() TYLKO przy zmianie stanu
  if (nowyStan != aktualnyStanEkran) {
    tft.fillScreen(TFT_BLACK);
    aktualnyStanEkran = nowyStan;
    // Narysuj etykiety statyczne raz
  }

  // Aktualizacja danych co 200 ms
  if (aktualnyStanEkran == 1) {
    sprintf(timerBuf, " %02lu:%02lu ", m, s);
    tft.drawCentreString(timerBuf, 64, 45, 4);
  }
}

Trzy widoki ESP32

  • Stan 0CYBER TRENER / Gotowy – wyświetlany gdy połączony z PC, nieaktywny trening
  • Stan 1TRENING – stoper (MM:SS, duża czcionka) + licznik powtórzeń w żółtym kolorze, odświeżane co 200 ms
  • Stan 2Rozłączono z PC – czerwony komunikat gdy BLE disconnected
Spacje w formacie " %02lu:%02lu " nadpisują stare znaki bez potrzeby czyszczenia — eliminacja artefaktów graficznych

# Po zaliczeniu ciosu: oczekuj na powrót
if event == "PUNCH_REGISTERED" and gotowy:
  self.gotowy_na_cios = False
  # ... ocena, zliczenie

# Kiedy ręka wraca do pozycji wyjściowej:
